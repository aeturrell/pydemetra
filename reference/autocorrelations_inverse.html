autocorrelations_inverse

autocorrelations_inverse(data, nar=30, n=15)

Compute inverse autocorrelation function.

Parameters

Name Type Description Default
data np.ndarray Input data. required
nar int Number of AR lags for computation. 30
n int Maximum lag. 15

Returns

Name Type Description
np.ndarray np.ndarray: Array of inverse autocorrelation values.
