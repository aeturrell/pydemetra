Function reference

(S)ARIMA models

Functions to wrangle (S)arima models

arima_difference Subtract one ARIMA model from another.
arima_model Create an ARIMA model.
arima_properties Compute ACF and spectrum of an ARIMA model.
arima_sum Sum ARIMA models with independent innovations.
sarima_decompose Decompose a SARIMA model into trend, seasonal, and irregular components.
sarima_estimate Estimate a SARIMA model by maximum likelihood.
sarima_hannan_rissanen Estimate SARIMA model using the Hannan-Rissanen method.
sarima_model Create a seasonal ARIMA model (Box-Jenkins).
sarima_properties Compute the ACF and spectrum of a SARIMA model.
sarima_random Simulate a SARIMA series.
ucarima_canonical Make a UCARIMA model canonical.
ucarima_estimate Estimate UCARIMA components from data.
ucarima_model Create a UCARIMA model from ARIMA components with independent innovations.
ucarima_wk Compute Wiener-Kolmogorov estimators for a UCARIMA component.

Calendars & holidays

Calendar definitions, holidays, and trading-day variables

calendar_td Generate trading day regressors with pre-defined holidays.
chained_calendar Create a calendar chaining two calendars at a break date.
easter_dates Return Easter Sunday dates for a range of years.
easter_day Create a holiday relative to Easter Sunday.
fixed_day Create a holiday on a fixed calendar day.
fixed_week_day Create a holiday on a specific weekday occurrence in a month.
holidays Generate daily holiday regressors from a calendar.
long_term_mean Compute long-term means for calendar regressors.
national_calendar Create a national calendar from a list of holidays.
single_day Create a one-time holiday on a specific date.
special_day Create a holiday from a pre-defined event.
stock_td Generate trading day regressors for stock series.
td Generate trading day regressors without holidays.
weighted_calendar Create a weighted combination of calendars.

Pre-defined and user-defined regression variables for seasonal adjustment

ao_variable Generate an additive outlier regressor.
easter_variable Generate an Easter effect regressor.
intervention_variable Generate an intervention variable.
julianeaster_variable Generate a Julian Easter effect regressor.
lp_variable Generate a leap year or length-of-period regressor.
ls_variable Generate a level shift regressor.
periodic_contrasts Generate periodic contrast variables.
periodic_dummies Generate periodic dummy variables.
ramp_variable Generate a ramp regressor.
so_variable Generate a seasonal outlier regressor.
tc_variable Generate a transitory change regressor.
trigonometric_variables Generate trigonometric variables at seasonal frequencies.

x13_dictionary Return all available X-13 output variable names.
x13_fast Run X-13 seasonal adjustment (results only, faster).
x13_regarima Run full RegARIMA model (X-13 flavour).
x13_regarima_spec Create a default RegARIMA specification (X-13 flavour).
x13_spec Create a default X-13 specification.
set_x11 Modify the X-11 decomposition parameters in a specification.

tramoseats

tramoseats_spec Create a default TRAMO-SEATS specification.
tramoseats_dictionary Return all available TRAMO-SEATS output variable names.

tramo_fast Run TRAMO modelling (results only, faster).
tramo_spec Create a default TRAMO specification.
set_seats Modify the SEATS decomposition parameters in a specification.

regarima_coef Extract coefficients from RegARIMA results.

regarima_residuals Extract residuals from RegARIMA results.
regarima_summary Generate a text summary of RegARIMA results.
regarima_vcov Extract variance-covariance matrix from RegARIMA results.

set_benchmarking Configure benchmarking in a specification.

density_t Compute the PDF of a Student t-distribution.
random_chi2 Generate random variates from a chi-squared distribution.
random_gamma Generate random variates from a Gamma distribution.

random_inverse_gaussian Generate random variates from an inverse-Gaussian distribution.
random_t Generate random variates from a Student t-distribution.

Statistical tests

Autocorrelations, normality tests, seasonality tests, and more

autocorrelations Compute autocorrelation function.
autocorrelations_inverse Compute inverse autocorrelation function.
autocorrelations_partial Compute partial autocorrelation function.
bowman_shenton Bowman-Shenton normality test.
doornik_hansen Doornik-Hansen normality test.
jarque_bera Jarque-Bera normality test.
kurtosis Kurtosis test.
ljungbox Ljung-Box test for independence.
mad Compute robust median absolute deviation.
seasonality_canova_hansen Canova-Hansen seasonality test.
seasonality_canova_hansen_trigs Canova-Hansen test using trigonometric variables.
seasonality_combined Combined seasonality test (X12-style).

skewness Skewness test.
td_canova_hansen Canova-Hansen test for stable trading days.
td_f Residual trading days F-test.
td_time_varying Likelihood ratio test on time-varying trading days.

test_of_up_down_runs Up-and-down runs test.

rangemean_tstat Range-mean regression T-statistic for log transformation decision.

Aggregation, interpolation, and other time-series helpers

compare_annual_totals Compare the annual totals of raw and seasonally adjusted series.
days_of Return the starting dates for each period of a time series.
ts_adjust Multiplicative adjustment for leap year or length of periods.
ts_interpolate Interpolate missing values in a time series.
tsdata_of Create a time series from values and dates.
